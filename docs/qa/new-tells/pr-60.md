Adds ten warn-tier tells to the recommended preset, from the survey of other slop detectors in #60. Four of them cover prose that claims everyone else missed something: `false-exclusivity`, `hidden-truth` and `real-problem-reframe`, with `false-suspense` for the reveal that usually goes with them. The other six are `rhetorical-self-answer`, `emphasis-crutch`, `staged-candor`, `mic-drop`, `negation-pivot` and `importance-flag`.

Each draft regex in #60 had 0 hits over the Django 3.2 docs, which stand in for human technical prose.

## Changes from the issue's regexes

- `real-problem-reframe`: the issue's regex needed an adjective before "question", so its own example "The question isn't X." did not fire. A bare "question" branch now fires, but only with a pivot (", it's" or ". It's") later on the same line, because "The question is not answered in the docs." is honest prose. "The problem isn't" still needs an adjective, since bug reports use it plainly.
- `false-exclusivity`: the verbs now take both forms, so "Most people miss the point." fires alongside "Nobody misses". <!-- deslop-lint-disable-line -->
